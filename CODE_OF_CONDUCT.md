# Code of Conduct

We are committed to providing a welcoming and harassment-free environment for everyone. We expect all contributors to uphold the principles below.

## Our Standards
- Use respectful and inclusive language.
- Be considerate of differing viewpoints and experiences.
- Accept constructive criticism and focus on improving the project.
- Show empathy toward other community members.
- Absolutely no harassment, trolling, or personal attacks.

## Scope
This Code of Conduct applies to all project spaces, including GitHub issues, pull requests, code reviews, discussions, and any other communication channels used by PathPay contributors.

## Enforcement
- Report unacceptable behavior to the maintainers via GitHub issues or direct contact if available.
- Maintainers will review and investigate all complaints and respond appropriately.
- Maintainers have the right to remove comments, reject contributions, or ban contributors for any behavior they deem inappropriate or threatening.
