# Code of Conduct

PathPay is a small open-source effort, and we want every contributor to feel welcome. These rules apply to all project spaces—issues, pull requests, code reviews, discussions, and any community channels.

## Our Standards
- Be respectful and inclusive in language and tone.
- Recognize and value diverse viewpoints.
- Offer constructive feedback focused on the work, not the person.
- Show empathy toward others and assume good intent.
- Harassment, discrimination, trolling, or personal attacks are never acceptable.

## Scope
This Code of Conduct governs all interactions within the PathPay GitHub organization, the repository, and any related communication maintained by the project owners.

## Reporting & Enforcement
- If you experience or witness unacceptable behavior, please contact the maintainers through GitHub issues or direct message (if available).
- Maintainers will review each report, take appropriate action, and keep incident details as confidential as possible.
- Maintainers may edit or remove comments, reject contributions, or temporarily/permanently ban individuals for violating this policy.
